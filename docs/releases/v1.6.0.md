# v1.6.0 — the dashboard's month, named on the dashboard

The month the dashboard is showing now says so above the summary card, and tapping
that name changes it. Before, the month lived behind a calendar icon in the app bar:
it changed the screen without ever saying which month you were now looking at, and
it asked for a *day* — through the platform's date picker — when the dashboard only
ever filters by month.

The picker now offers months only, one year at a time, from January 2020 up to the
current month. Months outside that range are still shown, greyed and unselectable,
rather than quietly missing. The chosen month comes back as the first day of that
month, so nothing in the app has to decide what a carried-over day would mean.

The statistics page keeps its own month and its own picker: the two screens are
opened one at a time and were never meant to move together, so a shared selection
would make opening one silently change the other.

**Installing.** Download the APK attached here, or use *Backup* → *Check for
updates*. If an older debug-signed build of this app is installed, uninstall it
first: Android refuses to update across a different signing key, and uninstalling
deletes the local database. The app is not on Google Play.

**Verifying what you downloaded.** The build details below carry this APK's
SHA-256, and the signing certificate is public: SHA-1
`b2f50e9c44f5724b9e17b57bd7b6a3e624f42cae` (the Console shows it colon-separated
as `B2:F5:0E:9C:44:F5:72:4B:9E:17:B5:7B:D7:B6:A3:E6:24:F4:2C:AE`). The README
section *Verifying a download*
(https://github.com/Zierch/expense_tracker#verifying-a-download) has the two
commands. Install from this page only: a copy forwarded through a chat app cannot
be checked against anything.

**Google Drive backup.** Sign-in runs on an OAuth consent screen that is still in
*Testing*, so only accounts on the test-user list can use it. Ask the maintainer
to add the Google address you want to export from, then use *Backup* → *Sign in
with Google* → *Export*. The JSON file is written to
`My Drive/Expense Tracker/expense-tracker-<YYYY-MM>.json` **in your own Drive**;
re-exporting the same month replaces that file. Nothing is uploaded anywhere
except when you press Export, and the app only requests the `drive.file` scope, so
it can only see the files it created itself.

**Privacy.** No analytics, no ads, no accounts, no server of ours. The update
check contacts GitHub's public release API and carries no account or personal
data — your IP address and a User-Agent string, as with any page load; details in
`PRIVACY.md`. Android Auto Backup and device-to-device transfer are disabled,
which means the phone's copy is the only copy unless you export it.
