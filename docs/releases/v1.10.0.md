# v1.10.0 — a refreshed tracker and full backups

Home, Statistics, and Settings have a new design with light and dark themes. The dashboard shows your balance and recent activity; Statistics offers week, month, and year views and PDF and CSV reports.

Google Drive backup now saves all transactions as one snapshot. Up to three verified snapshot versions are retained. Sync merges transactions without overwriting existing local data. Monthly backup files from older versions are not imported automatically or deleted. Sign in explicitly from Settings before using Drive.

New default subcategories include Coffee Shop and Fuel for expenses and Pocket Money for income. Existing transactions are retained during the database upgrade.

**Installing.** Download the APK attached to this release, or check for updates in Settings. An older debug-signed build must be uninstalled before installing the release-signed APK; uninstalling deletes local data.

**Google Drive access.** The OAuth consent screen is in testing; only approved test accounts can use Drive backup. The app requests the `drive.file` scope and uploads only when you start a backup.

**Privacy.** The app has no analytics, ads, or application server. The update check contacts GitHub's public release API. Android Auto Backup and device-to-device transfer are disabled, so keep a separate backup of your data.
