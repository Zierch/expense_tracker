# v1.10.1 — statistics and settings refinements

Statistics now shows period comparisons, labelled charts and a category donut with a legend. The launch screen includes the app name and tagline, and Settings can show the last-used Google account while signed out. Sign-in still requires an explicit action.

Allowance is no longer offered for new income transactions. Existing transactions using it are retained. When editing a transaction, its expense or income type cannot be changed.

**Installing.** Download the APK attached to this release or check for updates in Settings. An older debug-signed build must be uninstalled before installing the release-signed APK; uninstalling deletes local data.

**Google Drive access.** The OAuth consent screen is in testing; only approved test accounts can use Drive backup. The app requests the `drive.file` scope and uploads only when you start a backup.
