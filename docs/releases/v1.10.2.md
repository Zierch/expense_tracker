# v1.10.2 — the dashboard card you could not see, and the gap under the list

In light mode the "Every little entry counts" card was almost the same colour as
the page behind it. Its fill sat at 1.04:1 against the background and its border
at 1.14:1, so neither the card nor its edge read as anything at all — the mascot
and the Add button looked like they were floating loose under the balance. The
card keeps its pale green, a shade deeper now, with an edge that says where it
ends. Dark mode was never affected and looks exactly as it did.

The dashboard also left 88px of empty space between the last transaction and the
tab bar. That space was reserved for a floating add button, which the bottom
navigation replaced in v1.10.0; nothing was removed with the button, so scrolled
all the way down the list ended well short of the bottom. It now ends where the
list ends.

Nothing else changes. The database is untouched, so there is no upgrade step and
no waiting on first launch.

**Installing.** Download the APK attached to this release, or check for updates
in Settings. An older debug-signed build must be uninstalled before installing
the release-signed APK; uninstalling deletes local data.

**Google Drive access.** The OAuth consent screen is in testing; only approved
test accounts can use Drive backup. The app requests the `drive.file` scope and
uploads only when you start a backup.

**Privacy.** The app has no analytics, ads, or application server. The update
check contacts GitHub's public release API. Android Auto Backup and
device-to-device transfer are disabled, so keep a separate backup of your data.
